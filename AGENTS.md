# AGENTS.md — Chase's Repo

This repository is a static **iOS jailbreak APT repository** served via GitHub Pages at `https://chasedustevich.github.io/repo/` (`https://github.com/chasedustevich/repo.git`). Originally initialized from [supermamon/Reposi3](https://github.com/supermamon/Reposi3) by Raymond Velasquez, it has been streamlined and optimized to host **iOS 15–16+ rootless** (`iphoneos-arm64`) packages built with Theos in the sibling workspaces (`Asteroid`, `Snoverlay-2`, `axon-ios16-compatibility`, `s8edge`) for **Dopamine** and **Palera1n**, with full support for **Sileo**, **Zebra**, **Installer**, and legacy APT clients.

- Repository URL: `https://chasedustevich.github.io/repo/`
- Target Scheme: **rootless (`iphoneos-arm64`)** for iOS 15.0+ (with `Architectures: iphoneos-arm iphoneos-arm64` declared in `Release` for broad APT client compatibility).
- Package Managers Supported: Sileo (native JSON depictions + featured banners), Zebra, Installer, Cydia (web XML depictions).

## How it works

1. **APT Architecture & Index Formats (`Release`, `Packages*`):**
   - `Release` declares `Architectures: iphoneos-arm iphoneos-arm64` so both rootless (`iphoneos-arm64`) and multi-arch APT clients parse the source without warnings, while hosted packages specify `Architecture: iphoneos-arm64`.
   - `update-repo.sh` generates uncompressed `Packages` alongside `Packages.bz2`, `Packages.gz`, and `Packages.xz` (`-c9`), ensuring compatibility with modern package managers (Sileo/Zebra prefer `.xz` or `.gz`; Cydia uses `.bz2`).

2. **Automated Package Indexing & Depiction Injection (`update-repo.sh`):**
   - Runs `dpkg-scanpackages -m ./debs` and post-processes every package stanza in Python:
     - Normalizes `Filename:` to `./debs/<basename>.deb`.
     - Injects `Depiction: https://chasedustevich.github.io/repo/depictions/?p=<Package>` whenever `depictions/<Package>/info.xml` exists and `Depiction:` is absent.
     - Injects `SileoDepiction: https://chasedustevich.github.io/repo/depictions/<Package>/sileo.json` whenever `depictions/<Package>/sileo.json` exists and `SileoDepiction:` is absent.
     - Injects `Icon: https://chasedustevich.github.io/repo/depictions/<Package>/icon.png` whenever `depictions/<Package>/icon.png` exists and `Icon:` is empty or missing (never falling back to `CydiaIcon.png`).
     - Injects `Header: https://chasedustevich.github.io/repo/depictions/<Package>/banner.png` whenever `depictions/<Package>/banner.png` exists and `Header:` is empty or missing.
     - Synchronizes `<version>` in `depictions/<Package>/info.xml`, the first `<version>` in `depictions/<Package>/changelog.xml`, and `headerImage`, the `"Version"` `DepictionTableTextView` row, and the first `"Changelog"` tab `DepictionHeaderView` in `depictions/<Package>/sileo.json`.

3. **Sibling Workspace Sync (`./update-repo.sh --sync`):**
   - Reads `Package` and `Version` from each sibling workspace's `control` file (`../Asteroid`, `../Snoverlay-2`, `../axon-ios16-compatibility`, `../s8edge`) and scans its `packages/` directory for release `iphoneos-arm64` `.deb` archives matching that `Package` (ignoring `+debug` builds and legacy `iphoneos-arm` packages).
   - Selects the release `.deb` matching `control`'s `Version` (falling back to the highest version if no exact match), copies it into `debs/` whenever the staged version or SHA-256 differs, and prunes any other versions for that package in `debs/`.

4. **Dual Depiction Architecture (Web XML + Native Sileo JSON):**
   - **Sileo Native (`sileo.json`):** Uses `DepictionTabView` with `Details` and `Changelog` `DepictionStackView` tabs, `DepictionHeaderView`, `DepictionMarkdownView`, `DepictionTableTextView`, and `DepictionTableButtonView`.
   - **Web Depiction (`info.xml` + `changelog.xml`):** Rendered dynamically by `depictions/index.html` and `depictions/changelog.html` with `depictions/style.css` dark/light mode support.

## Adding / updating packages

Requires Homebrew `dpkg` (`dpkg-scanpackages`, `dpkg-deb`, `dpkg`), `python3`, `bzip2`, `gzip`, and `xz` (all checked by `update-repo.sh`, which prepends `/opt/homebrew/bin:/usr/local/bin` to `PATH`).

```sh
# Rebuild Packages indices from the .deb files currently in debs/
./update-repo.sh

# Sync newest release iphoneos-arm64 .deb builds from sibling workspaces,
# prune older duplicates in debs/, sync depiction versions, and rebuild indices
./update-repo.sh --sync
```

When introducing a brand-new package:
1. Build a release rootless `.deb` (`FINALPACKAGE = 1`, `THEOS_PACKAGE_SCHEME = rootless`, `iphoneos-arm64`) and place it in `debs/` (and add its workspace path to `sources` in `update-repo.sh` if using `--sync`).
2. Create `depictions/<bundle-id>/info.xml`, `changelog.xml`, and `sileo.json`.
3. Add a card in `index.html` and optionally a banner entry in `sileo-featured.json`.
4. Run `./update-repo.sh` and commit/push the updated `debs/`, `depictions/`, and `Packages*` files.

## Conventions and gotchas

- **Rootless release builds only:** Always build hosted `.deb` files with `FINALPACKAGE = 1` and `THEOS_PACKAGE_SCHEME = rootless` (`iphoneos-arm64`) so `Version` does not contain `+debug` suffixes and files stage under `/var/jb`.
- **Root ownership on manual repacks:** If repacking a `.deb` manually with `dpkg-deb -b`, always pass `--root-owner-group` so archive entries do not carry local macOS UIDs (`501`).
- **Keep `index.html` and `sileo-featured.json` updated manually** when bumping versions or adding/removing packages (`update-repo.sh` automatically updates `Packages*`, `info.xml`, and `sileo.json` versions, but `index.html` badge numbers are static HTML).
- **Empty `DEBIAN/control` fields:** Avoid trailing empty fields (e.g., `Conflicts:` or `Icon:` with no value) in tweak `control` files; `update-repo.sh` automatically populates per-package `Icon:` and `Header:` fields in `Packages` from `depictions/<Package>/icon.png` and `banner.png` when present.
- **Keep `Packages*` synchronized:** Never edit `Packages` by hand or update `debs/` without re-running `./update-repo.sh`, or SHA-256 checksums and file sizes will mismatch and package managers will reject downloads.
